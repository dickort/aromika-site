# AROMIKA PRODUCTION FINAL V4

Этот пакет собран под сценарий: **оставляем текущий проект aromika.info, удаляем старые блоки страниц и вставляем по одному T123 с финальным кодом**.

## 1. GitHub
Загрузите в КОРЕНЬ `dickort/aromika-site` файлы из папки `github/`:
- `site-shell-final-v1.css`
- `site-shell-final-v1.js`
- `assistant-v5-final.css`
- `assistant-v5-final.js`
- `pages-final-v1.css`
- `pages-final-v1.js`

Папку `github/romi/` загрузите как `/romi/` в репозитории.

Старые page-specific файлы в GitHub НЕ удаляйте: финальные бренд-страницы используют их как источник актуального продуктового каталога.

## 2. Tilda: общий HEAD
Tilda → Настройки сайта → Ещё → HTML-код для вставки в HEAD.
Вставьте содержимое `tilda/GLOBAL_HEAD_FINAL.txt` один раз.

## 3. Tilda: страницы
На каждой из 11 страниц:
1. Удалите старые блоки страницы.
2. Добавьте один блок T123.
3. Вставьте соответствующий файл из `tilda/pages/`.
4. Задайте URL по `PAGE_SETTINGS.md`.
5. Пока не публикуйте страницу отдельно, если остальные ещё не готовы.

## 4. Публикация
Когда все 11 страниц и общий HEAD готовы — опубликуйте все страницы. Затем откройте сайт в приватном окне.

## 5. Что работает
- единый header/footer;
- канонические маршруты без `/partneram`, `/proizvodstvo`, `/vacancies`;
- RU / ҚАЗ;
- light/dark;
- Romi V5;
- адаптивный mobile layout;
- главная и каталог брендов;
- акции из `data/promos-v3.json`;
- О компании + Производство + Сотрудничество на `/okompanii`;
- фильтры вакансий;
- представители по городам на странице контактов;
- бренд-страницы подтягивают продуктовые изображения/метаданные из текущих GitHub runtime-файлов и имеют fallback на бренд, если CDN временно недоступен.

## 6. Redirects
Создайте редиректы из `TILDA_REDIRECTS.txt`, чтобы старые внешние ссылки не давали 404.

## Важно
В этом пакете страницы больше не зависят от старых T123-разметок. Поэтому старые блоки действительно можно удалить. Старые GitHub runtime-файлы брендов пока оставьте: они используются как источник продуктовых данных.
