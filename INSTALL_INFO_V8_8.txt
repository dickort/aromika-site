ROMI INFO V8.8

Почему новый файл имеет новое имя:
предыдущие версии romi-v8-core.js/css могли оставаться в кэше jsDelivr.
V8.8 использует новые URL romi-v8-8-8.js / romi-v8-8-8.css.

Установка:
1. GitHub → dickort/aromika-site → main.
2. ДОБАВИТЬ в корень (не переименовывать):
   - romi-v8-8-8.js
   - romi-v8-8-8.css
3. Tilda → Настройки сайта → Ещё → HTML-код внутри HEAD.
4. Заменить текущий Romi HEAD содержимым GLOBAL_HEAD_ROMI_V8_8.txt.
5. Опубликовать все страницы.
6. Открыть aromika.info в приватном окне.

Исправлено:
- независимое окно info получает полный комплект стилей;
- старое узкое/пустое окно больше не должно определять геометрию V8;
- фото товара показывается целиком;
- сравнение показывает только выбранные товары и их характеристики.
