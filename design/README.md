# Aromika UI — пакет для проверки

Статус: draft. Обновляет внешний вид и доступность действующих блоков Tilda. Актуальные каталоги, адреса товаров и серверный модуль ROMI обслуживаются прежним кодом.

Файлы:

- `aromika-ui-v1.js` — подключает соседний CSS, нормализует меню и доступность элементов.
- `aromika-ui-v1.css` — стили с ограничением `html[data-aromika-ui="1"]`.
- `AUDIT-2026-09-12.md` — результаты аудита, границы проверки и дальнейшие задачи.
- `qa-results.json` — результаты проверок логики и контраста.
- `HEAD-preview.txt` — короткая вставка для тестовой страницы Tilda.
- `HEAD-safe-preview.txt` — вставка в общий HEAD с включением только по `?aromika_ui=preview`; закреплена на проверенном коммите с UI-пакетом.

## Ближайший шаг для владельца сайта

Добавить `HEAD-safe-preview.txt` в конец действующего общего HEAD и опубликовать страницы. Новый пакет загрузится только при наличии точного параметра `aromika_ui=preview`. Пример: `https://aromika.info/?aromika_ui=preview`. Для просмотра Antibak: `https://aromika.info/antibak?aromika_ui=preview`.

Режим действует для текущего URL и не сохраняется в браузере. При обычном переходе на другую страницу параметр нужно добавить к её адресу. Это режим проверки оформления, а не ограничение доступа: любой посетитель с такой ссылкой может посмотреть его. Для отключения достаточно открыть адрес без параметра. Переход к общему включению выполняется после визуальной приёмки.

## Проверка в Tilda

1. Использовать копию страницы. Добавить содержимое `HEAD-preview.txt` после действующих подключений в HEAD.
2. Опубликовать тестовую страницу. Для полной проверки DOM-части должна присутствовать текущая разметка шапки `#aromika-hero` и навигация `aromika-common-nav-final-v2.js`.
3. Визуально проверить 320, 390, 768, 1200, 1366 и 1440 px, RU/ҚАЗ и обе темы. Проверить переносы длинных подписей, отсутствие горизонтальной прокрутки, открытие и закрытие меню, переходы, карту, витрины брендов и работу ROMI.
4. Приёмка ещё не выполнена: облачный браузер заблокировал локальный предпросмотр. После неё можно включать пакет в общий HEAD и публиковать сайт.

Загрузка CSS выполняется скриптом после готовности DOM, поэтому при холодном кеше возможен краткий переход от старого оформления. Для окончательного выпуска CSS можно подключить отдельным link в HEAD; использовать id `aromika-ui-v1-css`, чтобы JS не добавлял его второй раз. Порядок CSS после существующих подключений нужно проверить в Tilda.

Откат: удалить только новую вставку и заново опубликовать страницы. Текущие блоки и старые подключения сохраняются.

Поддерживаемая среда: современные Chrome, Edge, Firefox и Safari. Визуальные тесты на реальных iOS/Android остаются обязательной частью приёмки.
